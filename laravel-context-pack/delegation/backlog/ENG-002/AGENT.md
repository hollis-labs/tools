# Assigned Agent

**Role**: Backend Engineer  
**Mission**: Implement Laravel project detection and metadata gathering that feeds all downstream generators.

**Key Skills Needed**: Node/Bun filesystem APIs (or shell tooling), Laravel knowledge (artisan commands, composer), process execution.

**Primary Goal**: Given a project path, collect core metadata (Laravel version, detected packages, database driver, available artisan commands) and persist it for other modules to consume.
