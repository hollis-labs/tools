# Assigned Agent

**Role**: Backend Engineer  
**Mission**: Produce route and controller summaries that feed the context pack, using Laravel CLI output as the primary source.

**Key Skills Needed**: Artisan command automation, data parsing, Markdown/JSON formatting, familiarity with Laravel routing conventions.

**Primary Goal**: Generate an API/route overview artefact (e.g., `api-endpoints.md`) containing HTTP verbs, URIs, controller methods, middleware notes, and grouped summaries.
